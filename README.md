# Wedgram Designs 💍✨

> Bespoke Wedding Invitation Videos & Digital Invites Crafted with Elegance

Wedgram Designs crafts exquisite wedding invitation videos, animated save-the-dates, and modern digital marriage invites uniquely tailored to reflect your love story.

---

## 🌟 Features & Highlights

- **Next.js 14 App Router & TypeScript**: Production-ready, server-side rendered, and statically optimized architecture.
- **Luxury Editorial Design**: Styled with a tailored palette (Warm Ivory `#FAF7F0`, Champagne `#E8D9BD`, Soft Beige `#EDE4D6`, Deep Charcoal `#292622`, and Muted Gold `#B69A68`).
- **Typography & Motion**: Paired serif headings and clean sans-serif body copy with smooth transitions.
- **Interactive Multi-Category Gallery**: Full showcase of video invitations (with inline native video playback), digital cards, and ceremonial captures.
- **Background AI & Web3Forms Enquiry Pipeline**:
  - Secure server-side processing via `/api/enquiry`.
  - Zero client-side API key leakage.
  - No intrusive AI chatbot widgets, badges, or popups—just a pristine, luxury wedding form.
- **Comprehensive Technical & Local SEO**:
  - OpenGraph & Twitter Cards.
  - JSON-LD Structured Data (`Organization`, `LocalBusiness`, `WebSite`, `Service`).
  - Dynamic `sitemap.xml` and `robots.txt`.
  - Semantic HTML5 heading hierarchy (`h1` through `h4`).
- **Responsive & Accessible**: Mobile-first design tested across phones, tablets, and desktop displays.

## 🚀 Tech Stack

- **Framework**: [Next.js 14](https://nextjs.org/) (App Router)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Form Submission**: Server-side Web3Forms API proxy with environment variable protection

## 🛠️ Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/roshan773/Wedgramdesigns.git
cd Wedgramdesigns
```

### 2. Install dependencies
```bash
npm install
```

### 3. Environment Variables
Create a `.env.local` file in the root directory:
```env
WEB3FORMS_ACCESS_KEY=your_web3forms_access_key_here
```
*(See `.env.example` for reference)*

### 4. Run the development server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

---

## 🌐 Deploy to Vercel

The repository is fully optimized for one-click deployment on [Vercel](https://vercel.com):

1. Import your GitHub repository to Vercel.
2. In **Environment Variables**, set:
   - `WEB3FORMS_ACCESS_KEY` = `your_web3forms_access_key`
3. Click **Deploy**.
